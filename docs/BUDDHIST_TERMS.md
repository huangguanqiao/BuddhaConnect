# Buddhist Terminology

Use consistent, context-sensitive terminology rather than forcing one translation across traditions.

| Chinese | Common English | Notes |
| --- | --- | --- |
| 佛陀 | Buddha | Clarify historical or generic sense where relevant |
| 佛法 | Dharma / Dhamma | Sanskrit / Pali forms differ |
| 四圣谛 | Four Noble Truths | Explain each truth without oversimplification |
| 八正道 | Noble Eightfold Path | Keep factor names consistent within an article |
| 无常 | Impermanence | Avoid equating with nihilism |
| 无我 | Not-self / non-self | Explain differences in interpretation |
| 缘起 | Dependent origination | Avoid reductive causal claims |
| 涅槃 | Nirvana / Nibbana | Match linguistic and traditional context |
| 慈悲 | Compassion | Distinguish from loving-kindness (慈) where relevant |

For quotations, retain the terminology of the named translation. When uncertain, document alternatives and request editorial review. Expand this glossary only with verified context.
