# Sources, Attribution and Verification

1. Prefer identifiable primary texts and reputable scholarly or established translation sources.
2. For each scripture-based assertion, record the work title, tradition/canon, translation or edition, and a stable reference when available.
3. Verify the exact wording against the cited edition before using quotation marks. If not verified, paraphrase and label it as explanation rather than scripture.
4. Never manufacture a citation, translation, canonical location or attribution.
5. Different Buddhist traditions may interpret concepts differently. Identify the tradition and avoid false consensus.
6. Respect copyright and translation licenses. A text being accessible online does not make it freely reusable.
7. Keep research notes and verification links in the PR description when a public-facing article does not yet have a dedicated citation component.
8. If verification is incomplete, mark the draft as needing source review and do not merge for publication.
