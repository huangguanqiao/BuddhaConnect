# Project Charter

BuddhaConnect is a Buddhist educational and editorial content website. The current codebase is a static Astro website intended for GitHub Pages, with the custom domain configured in Astro as https://code.buddhaconnect.com.

## Goals
- Present accessible, careful Buddhist learning materials.
- Make original sources and editorial interpretation distinguishable.
- Support maintainable, reviewable contributions by multiple AI assistants.

## Scope and unknowns
The current website is an early implementation. Future languages, denominations, audience segmentation, monetization and publishing cadence are not yet confirmed. Do not assume these are approved requirements.
